# LFG Class Names

**For WoW Forever.**

When you mouse over a group in the group finder, the tooltip lists its members, but shows each player's class only as the color of their name. With color blindness those colors are hard to tell apart. This addon adds the class icon and the class name, in your client's language, to every member.

- Works in Blizzard's own group finder and in addons that use the same tooltip, such as LFG Forever.
- Class icon and class name can each be turned off: Options → AddOns → LFG Class Names, or type `/lfgcn`.
- No libraries, nothing else to install.
